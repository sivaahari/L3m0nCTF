## 2. Decisions

1. **One builder, three places.** `plugins/l3mon_theme/pages/board.py` holds pure functions (no Flask, no database): `channel_keys`, `board_view`, `notice_lines`, `flt_count_text`. They take the dictionaries `board.build` already returns, so the golden tests feed them recorded data and need no CTFd. The registered value and the views are thin wrappers.
2. **Golden pairs.** `platform-ui/tools/golden-board.mjs` runs the prototype's own `boardView`, `noticeItems` and `phaseBanner` on named scenarios and writes `{input, expected}` pairs; the public repository holds the printed JSON under `plugins/l3mon_theme/tests/golden/` (invented data only). The Python test feeds `input` to the builder and compares with `expected`. `input` is made in the **real** shape (`id` is a database id that differs from `no`, `accent` and `picture` are present), so the mapping of item 2 above is exercised, not assumed.
3. **Equivalence test** (UI repository, `tests/theme-a-board.test.mjs`): for 13 situations of the board, 6 deep-linked programmes with their no-script page and 8 of the notifications page, the prototype's renderer and Jinja give the same HTML; markup in a name, a story, a sponsor or a notification is escaped; no "prototype" or "mock" on a real page.
4. **Gates are CTFd's.** I never render the board for somebody CTFd turns away; the adapter reads only `l3mon.board_page`.
5. **Withheld looks like missing.** `/board/<slug>` answers 404 when the slug is not in `build()["programmes"]` for this viewer (that list holds only what the viewer may see). One lookup, same wording and same query count as for a slug that never existed (a test compares the two).
6. **Instances** show their unavailable state when the overlay is off; tested both ways in M2.

## 4. Questions for the owner (asked in the first report; the recommendation is used until answered)

1. Must a flag, or buying a hint, work **without script**? Recommendation: no. Reading the page, the task, the files and any unlocked hint works without script; sending a flag and buying a hint need script, because CTFd's own routes are JSON only and a second route would bypass its rate limits. The prototype has no sentence saying so on the no-script page; I need the owner's wording (or a yes to "Send a flag needs JavaScript. Turn it on to send flags.").
2. Is it right that the channel number the crew types (0 to 99, `position`) is the one players see and the one that picks the art (scenes 0 to 7)? Recommendation: yes.
